# PULSE Engine Modules & Deep Dives
{: .no_toc }

Explore the mathematical foundations, zero-GC architecture, and C# API reference for all core powerhouse modules in **PULSE**.

---

## 🚀 Engine Pillars

### 1. [Spring Physics Studio](./spring-physics)
2nd-order harmonic oscillator dynamics for procedural recoil, bouncy buttons, organic transforms, and snappy physics without baked keyframes.

### 2. [Squash & Stretch](./squash-and-stretch)
True volume-conserving deformation ($X \times Y \times Z = 1$) for characters, weapons, jump arcs, and physical impacts across arbitrary impact vectors.

### 3. [Camera Shake & Trauma](./camera-shake)
Realistic non-linear camera shake using Perlin noise trauma models, directional punch vectors, and native Cinemachine integration.

### 4. [Time Management (HitStop & SlowMo)](./time-management)
Millisecond-precision frame freezes, eased slow-motion bullet-time, and automatic `fixedDeltaTime` physics synchronization.

### 5. [Audio Juice Engine](./audio-juice)
32-channel polyphonic pooled audio system with automatic pitch detune randomization, spatial falloff, and dynamic DSP low-pass ducking.

### 6. [Floating Combat Text](./floating-combat-text)
Zero-GC pooled TextMeshPro billboard popups with physics arcs, critical bounce animations, and status color schemes.

### 7. [Shaders & VFX Suite](./shaders-and-vfx)
Radial screen-space shockwave distortion, chromatic aberration blits, full-screen color flashes, and post-processing volume bursts.

### 8. [Ghosting Trails](./ghosting-trails)
High-performance phantom snapshot trails and after-images with material fade curves and mesh pooling for dashes and high-speed abilities.

### 9. [Renderer Flashing](./renderer-flash)
MaterialPropertyBlock damage flickering that prevents material duplication leaks and draw call spikes.

### 10. [Juicy UI Suite](./ui-juice)
Ready-to-use bouncy UI buttons, delayed ghost health bars, animated modal popups, and haptic feedback triggers.

### 11. [Time Rewind Engine](./time-rewind)
Ring-buffered physical state tracking allowing instant rewind and replay of positions, rotations, and velocities.

### 12. [Editor Tools, Diagnostics & Presets](./editor-tools-and-presets)
Command Hub, Setup Doctor, interactive curve editors, real-time hierarchy badges, and a curated library of 50+ AAA presets.
