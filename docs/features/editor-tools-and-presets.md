## 🛠️ Editor Windows & Tools

### 1. Central Pulse Dashboard
**Tools > Pulse Engine > Pulse Dashboard Pro**
* Live diagnostics and feedback trigger testing.
* Interactive production C# code snippet generator.
* Live event monitor log.

### 2. 1-Click Pulse Setup Doctor
**Tools > Pulse Engine > Pulse Setup Doctor & Scene Wizard**
* One-click automated validation of active Render Pipeline (URP/HDRP/Built-in), Main Camera tagging, AudioListener, and EventSystem.
* Automatically creates and configures singleton managers if missing.

### 3. Spring Dynamics Studio
**Tools > Pulse Engine > Spring Dynamics Studio**
* Real-time 2nd-order harmonic spring curve visualizer with interactive sliders.

### 4. Scene View Floating HUD & Hierarchy Badges
* Audition screen shakes, hitstops, and spring bounces directly in Scene View without entering Play Mode.
* Visual status pills in Unity Hierarchy identifying active Juice and Rewind components.
